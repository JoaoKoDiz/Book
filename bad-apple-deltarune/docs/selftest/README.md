# Self-test evidence (SYNTHETIC data — not the real reconstruction)

These files come from `python -m badapple_dr selftest --semantic-test`, run in the development
environment (4 CPU cores, no GPU) on **synthetic** videos generated by `badapple_dr/selftest.py`. They
show that the software works end-to-end. They are **not** Bad Apple!! or DELTARUNE footage and are
never used as source imagery.

* `selftest_report.json`: all 21 automated checks (all passed), timings, baseline accuracies.
* `synthetic_quality_report.json`: the `quality_report.json` the pipeline wrote for the synthetic run.
* `synthetic_frame_mapping_head.csv`: the first rows of the generated `frame_mapping.csv`.
* `synthetic_contact_sheet.png`: reference frames (left of each pair) and the selected library frames
  (right), as analysis images.
* `synthetic_comparison_frame.png`: one frame of the diagnostic `comparison_10s.mp4`.

The synthetic library is 224 s long (6,727 frames, 854×480 VP9 with a pillarboxed 4:3 "game" area).
It contains pixel-art overworld/battle/dialogue/fade/flash scenes, gameplay-styled renderings of the
reference shapes (textured, shifted, rescaled) as ground truth, and decoys: uniform frames with
exactly the reference's mean brightness, mirrored layouts and inverted polarity.
